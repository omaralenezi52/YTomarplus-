## المميزات
- ✅ **حذف الإعلانات** — إخفاء إعلانات الفيديو والبانرات
- ✅ **التشغيل بالخلفية** — استمرار الصوت عند إغلاق الشاشة
- ✅ **واجهة عربية 100%** بتصميم بنفسجي
- ✅ **خانة واحدة** داخل إعدادات يوتيوب تفتح كل المميزات

## طريقة الاستخدام
1. افتح يوتيوب → الإعدادات.
2. اضغط زر **«عمر شوف»** أعلى الشاشة.
3. فعّل المميزات من القائمة.

## البناء
يُبنى تلقائياً عبر **GitHub Actions** عند كل push.
تجد ملفات `.deb` جاهزة في تبويب **Actions → Artifacts**.

### بناء يدوي (Theos)
```bash
make package FINALPACKAGE=1
```
